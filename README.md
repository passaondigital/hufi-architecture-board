# HUFI Project Standard

Account-wide project foundation for repositories owned by `passaondigital`.

This repository contains the lightweight public rules that every project and coding/AI agent should follow. The deeper skill library, Project Wizard implementation and private operational details remain in the private `passaondigital/hufi-factory` repository.

## Core rule

Before substantial work:

**DISCOVER → VERIFY → REUSE → IMPLEMENT → TEST → VERIFY LIVE → DOCUMENT**

Never guess the current production state.

## Read first

- `docs/00_UNIVERSAL_PROJECT_STANDARD.md`
- `docs/01_PROJECT_BOOTSTRAP.md`
- `docs/02_AGENT_RELEASE_STANDARD.md`

## Status vocabulary

Use only:

`IDEA / PLANNED / FOUNDATION / BUILT / TESTED / STAGING / PRODUCTION / PARTIAL / BLOCKED / UNKNOWN`

`NOT TESTED` is never `PASS`.
`BUILT` is not `PRODUCTION`.

## Private extended system

Authorized HUFI agents may additionally use the private canonical skill library in:

`passaondigital/hufi-factory/skills/`

and the reusable starter templates in:

`passaondigital/hufi-factory/templates/PROJECT_STARTER/`

This public repository is intentionally the stable lightweight account-level foundation, not the full commercial/product implementation.
