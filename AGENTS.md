# Account-Level HUFI Agent Foundation

This repository is the lightweight public standards source for `passaondigital` projects.

For substantial project work:
1. read `docs/00_UNIVERSAL_PROJECT_STANDARD.md`
2. read `docs/01_PROJECT_BOOTSTRAP.md` when starting/resuming a project
3. read `docs/02_AGENT_RELEASE_STANDARD.md` before release or when claiming completion
4. prefer local project `00_START_HERE` / `PROJECT_MANIFEST` for project-specific truth
5. verify live/runtime truth before mutation
6. use UNKNOWN rather than guessing

Authorized internal HUFI agents may load deeper reusable skills from the private `passaondigital/hufi-factory` repository.
